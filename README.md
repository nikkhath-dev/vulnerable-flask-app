# Vulnerable Flask App - SQLi & XSS Demo 🔓

An intentionally vulnerable web application built with Python Flask to demonstrate and exploit OWASP Top 10 vulnerabilities for educational and interview purposes.

> **Disclaimer:** This project is for educational purposes only. Built to run on localhost (127.0.0.1). Do not deploy on public server.

### 🎯 Vulnerabilities Demonstrated
1. **SQL Injection (SQLi)** - Authentication Bypass
2. **Cross-Site Scripting (XSS)** - Reflected XSS

### 🛠️ Tech Stack
- Python
- Flask
- HTML / Jinja2

```bash
pip install flask
python app.py
